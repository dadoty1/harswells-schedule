# Harswells Schedule (app shell)

The static web app shell for the Harswells Construction & Design schedule app (installable PWA, works offline).

It holds **no job data**. Each device connects to its own data source after sign-in, and the data never passes through this repository or GitHub Pages.

Files: `index.html` (the app), `sw.js` (offline cache), `manifest.webmanifest` and `icons/` (home-screen install).
